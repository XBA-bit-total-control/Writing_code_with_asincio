### Программа написана с асинхронным подходом и использованием библиотек asyncio и aiohttp

Если требуется запуск нужно:

1. Создать и заполнить .env-файл
2. Установить библиотеки из requirements.txt
3. Запустить main.py

Примечание: В .env-example в качестве значения для DB_DRIVER уже указаны рекомендуемые значения
